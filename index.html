Intelligent Proofreading · 项目负责人

智能文档纠错服务

2026.07–2026.08

面向合同、公文的 AI 错字纠错系统，支持 PDF、Word、Excel 和纯文本， 输出保持原版式的结果页。

  • 架构：模型直接改文件，服务端 diff 定位变更；自研工具调用与覆盖率校验，六类错别字门禁。
  • 表格按单元格 R1C1 寻址，修改后仍能准确回填到原位置。
  • 技术栈：FastAPI + Gunicorn、LangChain + OpenAI 兼容网关（Qwen）、PyMuPDF、Vue3 + Vite + PDF.js、MySQL、MinIO、Gotenberg。
  • 交付：五容器编排、多架构镜像、离线一键部署。
  • 业绩：6,927 字合同植入 6 处错字全部命中，21 秒完成，覆盖率 100%，条款措辞零误改；13,276 字合同整篇 19–26 秒。
Python FastAPI LangChain Qwen PyMuPDF Vue3 MySQL Docker Compose

Document Parsing · 技术开发

文档解析服务

基于 Flask 的 OCR 服务，把图片、PDF、Office 转成带坐标的文本和表格。

  • PaddleOCR PP-OCRv6 + PP-DocLayoutV2 + RT-DETR + YOLO11 + ONNX Runtime。
  • 多页投票去水印、红章去除、方向矫正、表格单元格识别。
  • 输出字符级坐标和结构化表格，支持模型懒加载、版面缓存与 GPU 锁。
Flask PaddleOCR PP-DocLayoutV2 RT-DETR YOLO11 ONNX Runtime

Archive System · Python

档案管理系统

档案管理系统中的 Python 后端 OCR 服务，接收图像或 PDF，返回提取到的表格信息。

  • 将 PaddleOCR 的 .paddle 模型转为 ONNX，使用 onnxruntime 推理。
  • OpenCV 预处理：方向判断与转正、红色印章消除、图像二值化。
  • 通过预处理提升 OCR 准确度，返回表格结构给业务系统。
Python PaddleOCR ONNX Runtime OpenCV
